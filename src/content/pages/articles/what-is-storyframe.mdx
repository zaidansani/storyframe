# the inspiration behind storyframe

i came across this report on [erpx.open.gov.sg](https://erpx.open.gov.sg/) which i really liked the presentation of, and thought, why not show one of my projects in this way? i'd just graduated and wanted to show my FYP.

obviously like how most things go with random hobbyist developers, this devolved away from a one-time simple HTML implementation to a more generic framework for writing "reports" in mdx with support for interactive components.

in the end, what i really wanted to create was a way to make it easier to write technical reports for technical people that went beyond just pure text.

# what exactly does storyframe try to do?

it tries to change the world.... well obviously not HAHA but it's trying to make it easier to make articles a bit more interactive when possible. for example, interactive graphs are SO much more engaging to interact with (or maybe that's just my inability to sit still) than pure SVGs.

# Introduction

Container components live in `src/components/containers/`. Some are
registered in `src/lib/content/section-registry.ts` and used explicitly in
MDX (like `Accordion`); others run automatically on every article via
`src/layouts/AppLayout.astro` and are triggered by markdown syntax instead of
a tag (`CodeBlock`, `Sidenotes`, and callouts).

# Accordion

Collapsible groups of content, built from four components in
`src/components/containers/` and styled in `src/styles/containers/accordion.css`:
`Accordion` (the root), `AccordionItem` (one collapsible section),
`AccordionTitle`, and `AccordionContent`. Because content is passed as
regular children rather than a data prop, you can nest any MDX or Astro
content — including other components like charts — inside `AccordionContent`.

| Component          | Prop            | Type      | Required | Description                                         |
| ------------------ | --------------- | --------- | -------- | --------------------------------------------------- |
| `Accordion`        | `allowMultiple` | `boolean` | no       | Allow multiple items open at once (default `false`) |
| `AccordionItem`    | —               | —         | —        | Wraps one title/content pair                        |
| `AccordionTitle`   | —               | —         | —        | The clickable heading                               |
| `AccordionContent` | —               | —         | —        | The collapsible body                                |

# Tabs

Switchable panels, defined in `src/components/containers/Tabs.astro` and
styled in `src/styles/containers/tabs.css`. Unlike `Accordion`, panel content
is passed as named slots (`tab-0`, `tab-1`, ...) rather than an HTML string,
so you can nest real components — including charts — inside a tab.

| Param    | Type       | Required | Description          |
| -------- | ---------- | -------- | -------------------- |
| `labels` | `string[]` | yes      | Tab labels, in order |

Slot names correspond to each label's index (`tab-0` for the first label,
`tab-1` for the second, and so on).

# Carousel

A slideshow with arrow and dot navigation, built from `Carousel` (the root)
and `CarouselSlide` (one slide) in `src/components/containers/`, styled in
`src/styles/containers/carousel.css`. Like `Accordion`, slides are passed as
regular children, so anything — including charts — can go inside a
`CarouselSlide`.

| Component       | Prop   | Type      | Required | Description                                             |
| --------------- | ------ | --------- | -------- | ------------------------------------------------------- |
| `Carousel`      | `loop` | `boolean` | no       | Wrap from the last slide to the first (default `false`) |
| `CarouselSlide` | —      | —         | —        | One slide's content                                     |

# Callouts

Obsidian-style callouts, parsed from blockquotes by
`src/lib/markdown/remark-callouts.mjs` (icons resolved by
`src/lib/content/callout-icons.mjs`) and styled in
`src/styles/containers/callout.css`. Write a blockquote starting with
`[!type]`, optionally followed by a custom title. The type is
case-insensitive and controls the accent color and icon; unrecognized types
fall back to the default accent.

| Type                                                   | Color  |
| ------------------------------------------------------ | ------ |
| `note`, `info`                                         | blue   |
| `tip`, `hint`, `success`, `check`, `done`              | green  |
| `question`, `help`, `faq`                              | yellow |
| `warning`, `caution`, `attention`                      | yellow |
| `failure`, `fail`, `missing`, `danger`, `error`, `bug` | red    |
| `example`                                              | purple |
| `quote`, `cite`                                        | muted  |

# Code blocks

`src/components/containers/CodeBlock.astro` runs once per page load (mounted
by `AppLayout.astro`) and wraps every fenced code block in
`.article-content` with a copy-to-clipboard button, styled by
`src/styles/containers/code-block.css`. There's no component to place — any
` ``` ` fence in your MDX gets the button automatically.

<Tabs labels={["Display", "Code"]}>
    <Fragment slot="tab-0">
        ```python
        def hello():
            print("Hello world")

        hello()
        ```
    </Fragment>
    <Fragment slot="tab-1">
    ````mdx
    ```python
    def hello():
        print("Hello world")

    hello()
    ```
    ````
    </Fragment>
</Tabs>

# Sidenotes

`src/components/containers/Sidenotes.astro` also runs automatically on every
page, handling the click/toggle behavior for sidenote markers (styled by
`src/styles/containers/sidenotes.css`). The markers themselves come from
`src/lib/markdown/remark-sidenotes.mjs`, which turns `^[note text]` inline
syntax into a numbered, expandable reference — no component tag needed.

<Tabs labels={["Display", "Code"]}>
    <Fragment slot="tab-0">
        Here's a sentence with a sidenote.^[This is the note text, revealed on
        click.]
    </Fragment>
    <Fragment slot="tab-1">
    ```mdx
    Here's a sentence with a sidenote.^[This is the note text, revealed on click.]
    ```
    </Fragment>
</Tabs>

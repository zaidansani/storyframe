# Introduction

All charts live in `src/components/charts/` and share `title` and `height`
(pixels, default `320`) props. They render into a `<canvas>` via Chart.js,
queued through `window.__chartQueue` and drawn client-side by
`src/lib/charts/chart-client.ts`. Series colors come from the
`--chart-series-*` CSS variables — see [Theming](/docs/theming).

# BarChart

| Param      | Type                                  | Required | Description                       |
| ---------- | ------------------------------------- | -------- | ---------------------------------- |
| `title`    | `string`                              | no       | Caption shown above the chart     |
| `labels`   | `string[]`                            | yes      | X-axis category labels            |
| `datasets` | `{ label: string; data: number[] }[]` | yes      | One or more bar series            |
| `height`   | `number`                              | no       | Canvas height in px (default 320) |

<BarChart
    title="Monthly signups"
    labels={["Jan", "Feb", "Mar", "Apr"]}
    datasets={[{ label: "Signups", data: [12, 19, 8, 25] }]}
/>

```mdx
<BarChart
    title="Monthly signups"
    labels={["Jan", "Feb", "Mar", "Apr"]}
    datasets={[{ label: "Signups", data: [12, 19, 8, 25] }]}
/>
```

# BubbleChart

| Param      | Type                                                               | Required | Description                               |
| ---------- | ------------------------------------------------------------------ | -------- | ------------------------------------------ |
| `title`    | `string`                                                           | no       | Caption shown above the chart             |
| `datasets` | `{ label: string; data: { x: number; y: number; r: number }[] }[]` | yes      | One or more bubble series (`r` is radius) |

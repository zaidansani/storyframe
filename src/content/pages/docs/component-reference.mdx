# Introduction to charts

All charts live in `src/components/charts/` and share `title` and `height`
(pixels, default `320`) props. They render into a `<canvas>` via Chart.js,
queued through `window.__chartQueue` and drawn client-side by
`src/lib/chart-client.ts`.

# BarChart

| Param      | Type                                  | Required | Description                       |
| ---------- | ------------------------------------- | -------- | --------------------------------- |
| `title`    | `string`                              | no       | Caption shown above the chart     |
| `labels`   | `string[]`                            | yes      | X-axis category labels            |
| `datasets` | `{ label: string; data: number[] }[]` | yes      | One or more bar series            |
| `height`   | `number`                              | no       | Canvas height in px (default 320) |

<BarChart
    title="Monthly signups"
    labels={["Jan", "Feb", "Mar", "Apr"]}
    datasets={[{ label: "Signups", data: [12, 19, 8, 25] }]}
/>

```mdx
<BarChart
    title="Monthly signups"
    labels={["Jan", "Feb", "Mar", "Apr"]}
    datasets={[{ label: "Signups", data: [12, 19, 8, 25] }]}
/>
```

# Introduction to questions

All question components live in `src/components/questions/`, share a
consistent look via `src/styles/question.css`, and are graded client-side by
`src/lib/question-client.ts`. Every type accepts an optional `explanation`
string shown after the question is checked.

# MultipleChoice

Single correct answer, selected with radio buttons.

| Param         | Type       | Required | Description                                |
| ------------- | ---------- | -------- | ------------------------------------------ |
| `question`    | `string`   | yes      | The question prompt                        |
| `options`     | `string[]` | yes      | The list of choices                        |
| `answer`      | `number`   | yes      | Index into `options` of the correct choice |
| `explanation` | `string`   | no       | Shown after the answer is checked          |

<MultipleChoice
    question="What is the capital of France?"
    options={["Berlin", "Madrid", "Paris", "Rome"]}
    answer={2}
    explanation="Paris has been the capital of France since the 10th century."
/>

```mdx
<MultipleChoice
    question="What is the capital of France?"
    options={["Berlin", "Madrid", "Paris", "Rome"]}
    answer={2}
    explanation="Paris has been the capital of France since the 10th century."
/>
```

# MultipleResponse

One or more correct answers, selected with checkboxes.

| Param         | Type       | Required | Description                                   |
| ------------- | ---------- | -------- | --------------------------------------------- |
| `question`    | `string`   | yes      | The question prompt                           |
| `options`     | `string[]` | yes      | The list of choices                           |
| `answer`      | `number[]` | yes      | Indexes into `options` of all correct choices |
| `explanation` | `string`   | no       | Shown after the answer is checked             |

<MultipleResponse
    question="Which of these are prime numbers? (select all that apply)"
    options={["2", "4", "7", "9"]}
    answer={[0, 2]}
    explanation="2 and 7 are prime — 4 and 9 each have factors other than 1 and themselves."
/>

```mdx
<MultipleResponse
    question="Which of these are prime numbers? (select all that apply)"
    options={["2", "4", "7", "9"]}
    answer={[0, 2]}
    explanation="2 and 7 are prime — 4 and 9 each have factors other than 1 and themselves."
/>
```

# FillInTheBlank

Free-text entry, checked against a list of acceptable answers.

| Param           | Type       | Required | Description                                          |
| --------------- | ---------- | -------- | ---------------------------------------------------- |
| `question`      | `string`   | yes      | The question prompt                                  |
| `answers`       | `string[]` | yes      | Accepted answers (any match counts as correct)       |
| `caseSensitive` | `boolean`  | no       | Whether matching is case-sensitive (default `false`) |
| `explanation`   | `string`   | no       | Shown after the answer is checked                    |

<FillInTheBlank
    question="The chemical symbol for gold is ______."
    answers={["Au"]}
    explanation="Au comes from the Latin word for gold, aurum."
/>

```mdx
<FillInTheBlank
    question="The chemical symbol for gold is ______."
    answers={["Au"]}
    explanation="Au comes from the Latin word for gold, aurum."
/>
```
